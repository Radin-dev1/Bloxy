06 / STRAIGHT ANSWERS

Before you build.

Is the workspace actually interactive?

Yes. It is a Three.js workspace with orbit controls, selection, transforms, a property editor, working tool panels, undo and redo, and live generated geometry.

What do Gemini and Tripo each do?

Gemini plans Roblox scenes and action blueprints. Tripo handles text-to-3D and image-to-3D, returning textured GLB models for the viewport.

Does Bloxy change my Studio project automatically?

No. Web generation and Studio delivery are separate. You pair the plugin and approve the build before delivery.

Where are the API keys stored?

Provider keys belong in encrypted Cloudflare secrets. They are not placed in the GitHub Pages frontend or sent to Roblox Studio.

Is Bloxy affiliated with Roblox?

No. Bloxy is an independent creator tool and is not endorsed by Roblox Corporation.

What happens if a generation fails?

You are not charged. Failed AI requests are refunded automatically, and every charge is recorded in an append-only ledger you can audit.
