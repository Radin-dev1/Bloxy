Questions, answered plainly.

Is the workspace real?

Yes. The canvas is a Three.js editor with orbit controls, selectable objects, an Explorer, and editable properties. Gemini blueprint generation is connected through the Cloudflare backend.

Where are the API keys?

Gemini and Tripo keys stay in encrypted Cloudflare secrets. They are never included in GitHub Pages or sent to Roblox Studio.

Does Bloxy change my Studio project automatically?

No. Website generation creates a draft. Studio delivery requires pairing and explicit approval.

Is Bloxy affiliated with Roblox?

No. Bloxy is an independent creator tool and is not endorsed by Roblox Corporation.
